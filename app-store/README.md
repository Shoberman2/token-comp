# Burnt App Store screenshots

The `screenshots/6.9-inch` set is captured from the shipping SwiftUI interface on an iPhone 16 Pro Max simulator at the native 1320×2868 App Store size.

1. `01-feed.png` — friends' daily burn feed and share action
2. `02-ranks.png` — daily leaderboard
3. `03-post.png` — completed posting flow
4. `04-profile.png` — profile, streak, and usage history
5. `05-share.png` — post-publish sharing screen

The screenshot fixtures are enabled only for Debug builds through `BURNT_DEMO_ACCOUNT=1`; they are not included in the production experience.
